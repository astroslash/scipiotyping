# User stories

## Kenneth

- I can start practice with a single clear choice.
- I can see the next character and correct mistakes without losing my place.
- I can learn what WPM and accuracy mean.
- I can take a placement exercise and receive a sensible starting level.
- I can see why a lesson is recommended.
- I can explore subjects I enjoy without seeing graphic material.
- I can navigate and practice using only the keyboard.
- I can see personal progress without competing against strangers.

## Parent

- I can adjust goals and preferred difficulty.
- I can create and switch local student profiles.
- I can inspect trends, common errors, streaks, and achievements.
- I can export readable records and print a report.
- I can back up and restore all household data.
- I can add an original passage and receive clear validation errors.
- I can protect controls with an optional local PIN.
- I can reset data only after an unmistakable confirmation.

## Maintainer

- I can install dependencies and launch from documented PowerShell commands.
- I can update the schema without discarding existing progress.
- I can validate all content and run the full test suite locally.
- I can verify that no page requires an external network resource.
