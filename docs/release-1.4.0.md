# ScipioTyping 1.4.0 release verification

Version 1.4.0 expands Kenneth's offline library to 120 reviewed passages: twelve
in each of ten subjects. All sixty v1.3 passages and their IDs remain unchanged.

The sixty additions use original prose and structured references to museums,
heritage agencies, public-domain ancient texts and poems, FIDE, OpenStax, the
United Nations, and other established sources. Higher-level material receives
more space for evidence, competing causes, source limitations, and interpretation.

Regression coverage fixes the category totals, new difficulty distribution,
Level 2–5 word bands, original-rights status, reviewed status, and HTTPS source
records. Release verification includes strict content validation, a fresh
inventory, database upgrade checks, offline asset inspection, and the complete
Microsoft Edge typing workflow.
