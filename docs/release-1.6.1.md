# ScipioTyping 1.6.1

Version 1.6.1 makes the public app address a reliable learner-selection entry
point. Opening the local shortcut or the Vercel root URL clears the remembered
learner and displays Kenneth, William, and Alice with no profile preselected.

After selection, the learner dashboard lives at `/home`. The ScipioTyping brand
and ordinary in-app navigation continue to return there without interrupting an
active learner. No database migration is required.
